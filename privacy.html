개인정보처리방침

DriftTone Uploader · 최종 갱신 2026년 8월 29일

DriftTone Uploader(이하 "본 도구")는 운영자 본인이 소유한 YouTube 채널에 영상을 올리고 그 실적을 확인하기 위해 만든 개인용 도구입니다. 운영자 한 사람만 사용하며, 외부 사용자에게 제공하거나 배포하지 않습니다.

수집하는 정보

본 도구는 이용자에게서 개인정보를 수집하지 않습니다. 회원가입, 문의 양식, 분석 스크립트, 광고 추적기를 두지 않습니다.

운영자가 본인의 Google 계정으로 로그인하면, 그 인증 결과로 발급된 토큰이 운영자의 개인 컴퓨터에만 저장됩니다. 이 토큰은 외부로 전송되지 않습니다.

Google 사용자 데이터의 이용

본 도구는 다음 권한을 요청하며, 각 권한은 아래 목적으로만 쓰입니다.

  • youtube.upload — 운영자 본인 채널에 영상 업로드
  • youtube.force-ssl — 본인 영상의 제목·설명·썸네일 수정, 재생목록 정리, 본인 채널 댓글 게시
  • youtube.readonly — 본인 채널과 영상 목록 조회
  • yt-analytics.readonly — 본인 채널의 조회수·시청시간 등 실적 조회

가져온 데이터는 운영자의 개인 컴퓨터에서만 처리되며, 다른 사람이나 다른 서비스에 제공·판매·공유하지 않습니다. 광고 목적으로 사용하지 않습니다.

보관과 삭제

인증 토큰과 조회한 실적 데이터는 운영자의 로컬 디스크에 보관됩니다. 운영자는 언제든 해당 파일을 삭제할 수 있고, Google 계정 권한 설정에서 본 도구의 접근 권한을 회수할 수 있습니다. 권한을 회수하면 저장된 토큰은 즉시 무효가 됩니다.

제3자 제공

없습니다. 본 도구는 Google API 외의 외부 서버로 사용자 데이터를 보내지 않습니다.

Google API 서비스 사용자 데이터 정책

본 도구의 Google API 사용은 Google API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.
